# Support

- Start with [QUICKSTART.md](QUICKSTART.md).
- Check the troubleshooting section and configuration examples in [README.md](README.md).
- Search existing GitHub issues before opening a new one.
- Use the bug or feature request template and remove all credentials and personal information.
- Report security issues privately according to [SECURITY.md](SECURITY.md).

Community support is best effort. Do not use public issues to request help with a compromised secret; rotate it first.

# Code of Conduct

## Our commitment

We want participation in Starry Agent Connector to be useful, respectful and safe for people with different backgrounds, experience levels and communication styles.

## Expected behavior

- Discuss technical decisions with evidence and respect.
- Give actionable feedback about code and behavior, not the person.
- Respect local privacy. Do not ask others to publish credentials, personal identifiers, private repositories or machine paths.
- Credit prior work and clearly disclose security implications.
- Accept maintainers' decisions about scope and responsible disclosure.

## Unacceptable behavior

- Harassment, threats, discrimination or personal attacks.
- Publishing another person's private information or credentials.
- Pressuring contributors to run untrusted code or expose local Agents.
- Deliberately bypassing security controls or hiding a known vulnerability.
- Spam, sustained disruption or bad-faith participation.

## Enforcement

Report conduct concerns privately to a repository maintainer through the contact method listed on their GitHub profile. Do not publish sensitive details in an issue. Maintainers may edit or remove content, issue a warning, temporarily restrict participation, or permanently ban participation depending on severity and recurrence.

This policy applies in repository spaces and whenever someone is representing the project elsewhere.
